- Staff Engineer
- Principal Engineer
- Engineering Manager

## Technologies / Skills
- Python (FastAPI, Django)
- Celery / Temporal

- AWS / GCP / Azure

- Redis

## Location / Time posted Preferences
- Remote (preferred)
- Hybrid (preferred, London UK acceptable)
- Location: London
- Post date: prefer less than 2 weeks old

- Target: £130,000–£150,000

- Avoid: Pure outsourcing / body shop agencies

- Stage: Any

## Culture & Values
- Remote-first culture
- Strong engineering culture with technical leadership
- Autonomy and ownership
- Work-life balance
- Interesting technical challenges

## Exclusions
- No pure front-end only roles
- Job posting older than 4 weeks
